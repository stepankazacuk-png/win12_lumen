# Люмен — школьная презентация

Готовый набор для выступления: сама презентация, картинки, текст рассказа и опрос.

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | Презентация, 7 слайдов. Открывается двойным щелчком |
| `Люмен-презентация.pdf` | То же самое для сдачи — по слайду на страницу |
| `ТЕКСТ-ДЛЯ-РАССКАЗА.md` | Что говорить на каждом слайде |
| `ОПРОС-ДЛЯ-ОДНОКЛАССНИКОВ.md` | Текст опроса и как его провести |
| `img/` | 13 снимков системы |
| `slides/` | Снимки всех 7 слайдов |
| `qr-lumen.png` | QR-код на систему — показать на экране |

## Как вести презентацию

| Клавиша | Действие |
|---|---|
| `→` или `Пробел` | следующий слайд |
| `←` | предыдущий слайд |
| `N` | показать заметки — что говорить |
| `F` | во весь экран |

Щелчок справа листает вперёд, слева — назад. Точками сверху можно прыгнуть на любой слайд.

## Семь слайдов

1. **Титул** — что такое «Люмен»
2. **Задача** — придумать систему, которой нет
3. **Как я это делала** — пять этапов и кусочки кода
4. **Включение и вход** — кнопка питания, загрузка, пароль
5. **Внутри системы** — рабочий стол и окна
6. **Программы** — 16 приложений и защита
7. **Итоги и опрос** — цифры, QR-код и голосование

## Перед выступлением

1. Проверьте, что система открывается: <https://work-1-jkolqlpeuzvxiuna.prod-runtime.all-hands.dev/>
2. Откройте `index.html` и нажмите `F` — на весь экран.
3. Нажмите `N` — увидите подсказки, что говорить. Перед началом нажмите `N` ещё раз, чтобы скрыть.
4. Проверьте интернет: шрифты подгружаются из сети. Без сети слайды откроются, но шрифт будет попроще.

## Запасной вариант

Если система не открывается по ссылке — покажите снимки из папки `img/`.
Они лежат в презентации, так что рассказ не пострадает.
