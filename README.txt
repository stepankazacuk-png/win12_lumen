ЛЮМЕН — вымышленная веб-операционная система
============================================

Что это
-------
«Люмен» — придуманная операционная система, которая работает прямо в браузере.
Внутри: экран включения, блокировка с кодом, рабочий стол, окна, панель задач,
меню «Пуск», проводник, блокнот, терминал, браузер, игры и настройки.
Названия и устройство системы вымышлены.


Как запустить
-------------
Нужен Python 3 (он уже стоит на Linux и macOS; на Windows скачайте с python.org
и при установке отметьте галочку «Add Python to PATH»).

Windows
  1. Распакуйте архив.
  2. Двойной щелчок по файлу  Запустить-Windows.bat
  3. Браузер откроется сам. Если нет — зайдите на http://localhost:12000/

macOS / Linux
  1. Распакуйте архив.
  2. В терминале перейдите в папку с файлами и выполните:
         chmod +x Запустить-Linux-macOS.command
         ./Запустить-Linux-macOS.command
  3. Браузер откроется сам. Если нет — зайдите на http://localhost:12000/

Запуск вручную (любая система)
  В папке с файлами выполните:
         python3 server.py 12000
  и откройте http://localhost:12000/

Чтобы остановить — закройте окно терминала или нажмите Ctrl+C.


Почему нужен server.py, а не обычный просмотр файла
---------------------------------------------------
Если открыть index.html двойным щелчком, система тоже запустится, но
встроенный браузер работать не будет: ему нужен сервер, который поднимает
настоящий Chromium. С server.py работает всё.


Вход в систему
--------------
1. На экране включения нажмите большую кнопку питания.
2. Введите имя учётной записи и пароль, затем нажмите «Войти».

Учётных записей может быть несколько: их заводит администратор в панели
администратора. Учётная запись владельца «Степан» встроена, пароль и код
владельца заданы заранее. В файлах лежат только шифртекст записи и отпечаток
кода — открытого текста нет.

Пароли не хранятся — ни открытым текстом, ни отпечатком. Из пароля выводится
ключ, которым зашифрована запись учётной записи. Верный пароль её
расшифровывает, неверный не проходит проверку. Поэтому копия хранилища не
даёт ни пароля, ни возможности подменить роль.

Код владельца — главный ключ системы. Он открывает панель администратора и
позволяет задать новый пароль администратора, если пароль забыт. В исходниках
открытым текстом его нет: там только отпечаток (SHA-256 с солью и повторами),
из которого его не восстановить. Так сделано намеренно — репозиторий
публичный.

Если пароль забыт, нажмите «Забыли пароль?», введите имя учётной записи и код
владельца — затем задайте новый пароль. Сменить пароль можно только
администратору: обычному пользователю система ответит, что смена пароля
недоступна. Это работает и при включении, и при блокировке.

Добавить или удалить пользователя, сменить его пароль и роль можно в панели
администратора, вкладка «Пользователи». Панель открывается только
администратору и только по коду владельца: у обычного пользователя этой
вкладки в «Параметрах» нет.

Имя пользователя по умолчанию: Степан. Домашняя папка: C:\Users\Степан.

Кнопки «Пропустить» нет намеренно: включение только через кнопку питания.


Значок «Компьютер»
------------------
Значок встроенный — четырёхлучевая звезда, как у голосового помощника
«Джимини». Он же служит знаком системы: на загрузке, в меню «Пуск», на
блокировке, в «О системе» и на экране выключения. Отдельного файла с
картинкой нет, менять ничего не нужно.


Про музыку
----------
В «Музыке» играют записи с YouTube Music. У части песен владельцы запрещают
показ внутри других программ — так YouTube защищает официальные клипы. Тогда
система честно сообщает об этом и предлагает кнопку «Открыть в YouTube Music»,
а не листает список молча. Ограничение задаёт YouTube, обойти его нельзя.


Управление
----------
Мышь
  Двойной щелчок по значку — открыть.
  Правый щелчок — меню.
  Тянуть за заголовок — переместить окно; за край — изменить размер.

Телефон и планшет
  Двойной тап — открыть, долгое нажатие — меню.
  Окна открываются во весь экран, поворот экрана перестраивает их сам.

Если система тормозит
---------------------
«Люмен» сам следит за плавностью. Если кадры проседают, включается облегчённый
режим: убираются размытия и плавающий фон. Переключить вручную можно в
«Параметрах» или в панели администратора.
