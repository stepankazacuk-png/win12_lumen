# Люмен

Вымышленная операционная система, которая работает прямо в браузере. Никаких
сборок и зависимостей: только HTML, CSS и JavaScript.

Внутри: экран включения, блокировка с кодом, рабочий стол, окна, панель задач,
меню «Пуск», проводник, терминал, браузер, игры, музыка и настройки. Названия и
устройство системы вымышлены.

**Вход:** кнопка питания → свой код владельца. Паролей по умолчанию нет —
система не хранит ни одного кода в открытом виде.

> **Впервые здесь?** Пошаговая инструкция простым языком — в файле
> [ЗАПУСК.md](ЗАПУСК.md): что нажать, что должно получиться и что делать, если
> не получилось.

## Запустить с GitHub (без установки)

Система выложена как статический сайт, поэтому запускается одним щелчком.

1. Откройте <https://stepankazacuk-png.github.io/win12_lumen/>
2. Нажмите большую кнопку питания и введите пароль учётной записи. Забыли
   пароль — нажмите «Забыли пароль?» и введите код владельца.

Сайт пересобирается сам при каждом обновлении кода — отдельная настройка для
этого не нужна. Если ссылка ещё не открывается, включите публикацию один раз:
в репозитории **Settings → Pages → Source → Deploy from a branch**,
затем **Branch: main**, папка **/ (root)**, кнопка **Save**.

Такой запуск работает в любом браузере: на компьютере, телефоне и планшете.
Устанавливать Python не нужно.

**Что не работает при запуске с GitHub Pages.** Pages отдаёт только файлы, без
программы на сервере, а встроенному браузеру нужен сервер: он поднимает
настоящий Chromium. Без сервера окно браузера так и пишет: «Сервер не запущен.
Откройте систему через server.py».

Всё остальное работает полностью: экран включения, вход по коду, рабочий стол,
окна, панель задач, «Пуск», терминал, проводник, блокнот, калькулятор, игры,
музыка, фотографии и настройки. Полный браузер включается при запуске на своём
компьютере (см. ниже).

## Запустить на своём компьютере

Так работают все возможности, включая встроенный браузер: сервер поднимает
настоящий Chromium и показывает его экран в окне.

Нужен Python 3. На Linux и macOS он уже стоит; на Windows скачайте с
[python.org](https://www.python.org/downloads/) и при установке отметьте
галочку **Add Python to PATH**.

**Windows**

    Запустить-Windows.bat

Двойной щелчок по файлу. Браузер откроется сам, иначе зайдите на
<http://localhost:12000/>.

**macOS и Linux**

    chmod +x Запустить-Linux-macOS.command
    ./Запустить-Linux-macOS.command

**Вручную, любая система**

    python3 server.py 12000

и откройте <http://localhost:12000/>.

Чтобы остановить — закройте окно терминала или нажмите `Ctrl+C`.

## Скачать архивом

Готовый архив лежит в облаке и скачивается одним щелчком:

<https://github.com/stepankazacuk-png/win12_lumen/releases/latest>

Раздел **Assets** → **lumen.zip**. Распакуйте и запустите файл для своей
системы.

Собрать архив самому можно так:

    python3 mkzip.py

Получится `lumen.zip` из свежих файлов проекта.

## Почему нужен server.py, а не обычный просмотр файла

Если открыть `index.html` двойным щелчком, система тоже запустится, но
встроенный браузер работать не будет: ему нужен сервер, который поднимает
настоящий Chromium. С `server.py` работает всё.

## Управление

**Мышь.** Двойной щелчок по значку — открыть. Правый щелчок — меню. Тянуть за
заголовок — переместить окно, за край — изменить размер.

**Телефон и планшет.** Двойной тап — открыть, долгое нажатие — меню. Окна
открываются во весь экран, поворот экрана перестраивает их сам.

## Значок системы

Значок встроен в код — четырёхлучевая звезда с градиентом. Он же служит знаком
системы: на загрузке, в меню «Пуск», на блокировке и на экране выключения.
Отдельного файла с картинкой нет.

## Если система тормозит

«Люмен» сам следит за плавностью. Если кадры проседают, включается облегчённый
режим: убираются размытия и плавающий фон. Переключить вручную можно в
«Параметрах» или в панели администратора.

## Устройство проекта

| Файл | Что внутри |
| --- | --- |
| `index.html` | Каркас оболочки: загрузка, блокировка, рабочий стол, панель задач, «Пуск», виджеты, меню |
| `styles.css` | Оформление: цвета, стекло, обои, окна, приложения |
| `os.js` | Ядро: значки, состояние, файловая система, окна, приложения, оболочка |
| `server.py` | Сервер: файлы, прокси `/__proxy`, живой Chromium через `/__live` |
| `mkzip.py` | Сборка архива `lumen.zip` |
| `e2e.html` | Автопроверка системы |
