# Как запустить «Люмен» — простая инструкция

Эта инструкция для тех, кто не программирует. Всё по шагам: что нажать, что
должно получиться и что делать, если не получилось.

В системе есть три способа запуска. Начните с первого — он самый простой.

---

## Способ 1. Просто открыть ссылку (ничего скачивать не нужно)

Подходит для телефона, планшета и любого компьютера.

**Что делать**

1. Откройте в браузере ссылку:

   **https://stepankazacuk-png.github.io/win12_lumen/**

2. Появится экран с кнопкой включения. Нажмите её.
3. При первом запуске система попросит придумать код владельца и один раз
   покажет код восстановления. Запишите оба — пароля по умолчанию нет.
4. Готово — вы на рабочем столе.

**Что работает:** экран включения, вход по коду, рабочий стол, окна, меню
«Пуск», терминал, проводник, блокнот, калькулятор, игры, музыка, фотографии,
настройки.

**Что не работает:** встроенный браузер. В нём будет написано: «Сервер не
запущен. Откройте систему через server.py». Так и должно быть: браузеру нужна
программа на сервере, а GitHub отдаёт только файлы. Полный браузер заработает
при способе 2.

**Если ссылка не открывается**

- Подождите 2–3 минуты и обновите страницу: после обновления кода сайт
  собирается заново.
- Проверьте, что адрес скопирован целиком, со слэшем на конце.

## Способ 2. Запустить у себя на компьютере (полная версия)

Здесь работает всё, включая встроенный браузер с настоящими сайтами.

**Что понадобится:** Python 3 — бесплатная программа. Скорее всего, у вас уже
стоит. Проверить просто: откройте терминал и напишите `python3 --version`.

- **Windows:** если Python нет, скачайте с
  [python.org](https://www.python.org/downloads/). При установке обязательно
  поставьте галочку **Add Python to PATH** — без неё не заработает.
- **macOS и Linux:** Python уже установлен, ничего делать не нужно.

### Шаг 1. Скачать архив

1. Откройте страницу со свежими версиями:

   **https://github.com/stepankazacuk-png/win12_lumen/releases/latest**

2. В разделе **Assets** нажмите **lumen.zip**. Файл скачается.

### Шаг 2. Распаковать

- **Windows:** правый щелчок по `lumen.zip` → **Извлечь всё** → **Извлечь**.
- **macOS:** двойной щелчок по архиву.

Появится папка `lumen` с файлами внутри.

### Шаг 3. Запустить

**Windows**

Двойной щелчок по файлу **Запустить-Windows.bat**.

Откроется чёрное окно и через пару секунд — браузер с системой. Чёрное окно
закрывать нельзя: это и есть сервер.

**macOS и Linux**

1. Откройте терминал в папке `lumen` (в macOS: правый щелчок по папке →
   **Службы** → **Новый терминал в папке**).
2. Выполните две команды по очереди:

   ```
   chmod +x Запустить-Linux-macOS.command
   ./Запустить-Linux-macOS.command
   ```

**Если ничего не открылось**

Откройте браузер и зайдите вручную: **http://localhost:12000/**

**Как остановить**

Закройте чёрное окно терминала или нажмите `Ctrl+C` в нём.

## Способ 3. Запустить командой (для тех, кто уже освоился)

В распакованной папке:

```
python3 server.py 12000
```

Затем откройте **http://localhost:12000/**

## Что делать, если что-то не так

**«Не найден Python» или окно сразу закрывается**

Python не установлен или не добавлен в PATH. Установите его с
[python.org](https://www.python.org/downloads/) и при установке поставьте
галочку **Add Python to PATH**. Затем запустите файл снова.

**Браузер пишет «Сервер не запущен»**

Значит, вы открыли систему без `server.py` — например, двойным щелчком по
`index.html` или через ссылку GitHub Pages. Так и задумано. Для полной версии
запускайте через файл **Запустить-Windows.bat** (способ 2).

**Пишет «Порт 12000 уже занят»**

Сервер уже запущен в другом окне. Откройте http://localhost:12000/ — скорее
всего, система уже работает там. Если это не так, закройте лишнее чёрное окно и
запустите файл снова.

**Система тормозит**

«Люмен» сам включает облегчённый режим, когда кадры проседают: убирает размытия
и плавающий фон. Переключить вручную можно в **Параметрах** или в панели
администратора.

## Вход в систему

| Что | Значение |
| --- | --- |
| Вход | кнопка питания → свой код владельца |
| Пользователь | Степан |
| Папка пользователя | `C:\Users\Степан` |

Код владельца вы задаёте сами при первом запуске. Пароля по умолчанию нет:
система хранит не сам код, а только отпечаток, из которого его не восстановить.

Забыли код? На экране входа нажмите «Забыли код?»:

- если вы сохранили код восстановления — введите его и задайте новый код;
- если кода восстановления нет — остаётся полный сброс. Файлы и настройки
  будут удалены, система вернётся к состоянию первого запуска.

Кнопки «Пропустить» нет — вход только через кнопку питания. Так задумано.
